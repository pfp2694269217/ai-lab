# ai-lab

AI 学习实验仓。用来放可在线查看的成果页，不作为代码仓库使用。

## 目录

| 文件 | 说明 |
|---|---|
| `dashboard.html` | 30 个任务包的进度看板（由本地 Markdown/HTML 版本另存，Pages 域名下统一用英文名） |
| `.gitignore` | 拦截办公软件锁文件（`~$*`）、依赖目录与凭据类文件 |

## 为什么不叫 dashboard 仓

仓名叫 `ai-lab`，页名叫 `dashboard.html`。若仓名也叫 `dashboard`，Pages 地址会变成
`.../dashboard/dashboard.html`，重复且难认。
